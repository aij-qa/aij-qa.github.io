# Ariful Islam Portfolio

This repository holds my personal portfolio site. It is live at **https://aij404.github.io/**.

I am a Senior SQA Engineer with 6+ years in testing and QA. I lead QA for the customer solutions of an enterprise retail POS platform used by large retail chains in the Nordics, Greenland, Germany and Poland. I also built its agentic test automation: AI agents that write, run, review and report Playwright tests, with a person approving every change.

## What the site shows

- Agentic QA: the agent pipeline, how its parts connect, and its guardrails
- Experience at Fiftytwo Digital, Intellier and bdtask
- Two case studies: manual QA and agentic E2E automation on a retail POS
- 21 projects across retail POS, automation and enterprise systems
- Writing, skills, credentials and contact details
- A Download CV button that gives you my latest CV as a PDF

## How it is built

The site is plain HTML, CSS and JavaScript in one file. It has no build step and no framework. The fonts come from Google Fonts. The light and dark themes follow the visitor's system setting, and the layout works on phones, tablets and desktops. GitHub Pages hosts it straight from the `main` branch.

## How to update it

1. Upload the changed file with the same name and commit it to `main`.
2. GitHub Pages publishes the change in one or two minutes.
3. To update the CV, upload the new PDF with the exact name `Resume_Ariful_Islam.pdf`. The Download CV buttons then give out the new file.
